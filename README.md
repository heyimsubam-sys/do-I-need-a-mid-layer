# Mid-Layer Protocol 🏔️

**Mid-Layer Protocol** is a professional-grade alpine gear assistant designed for skiers and snowboarders. It combines real-time weather data with AI-powered analysis to provide precise layering strategies and mountain verdicts.

## 🚀 Features

- **Global Resort Search**: Find any mountain using a hybrid search strategy that combines standard geocoding with AI suggestions (✨) for precise resort locations.
- **Dynamic Alpine Forecast**: View a 5-day mountain-specific forecast including snowfall accumulation, UV index, wind speeds, and cloud cover.
- **AI Mountain Verdict**: Get a high-octane gear report generated by Gemini, focusing on base, mid, and shell layers plus visibility advice.
- **Atmospheric UI**: A sleek, dark-mode interface that shifts its background based on real-time weather conditions (Snow, Sunny, Cloudy, Rain).

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS
- **Animations**: Motion (framer-motion)
- **AI Engine**: Google Gemini (via `@google/genai`)
- **Weather Data**: Open-Meteo API
- **Icons**: Lucide React

## ⚙️ Setup

To run this application locally or in a deployed environment, you must provide a Gemini API Key.

1.  **Get a Gemini API Key**: Visit the [Google AI Studio](https://aistudio.google.com/) to generate your key.
2.  **Configure Environment**: Add your key to the application settings or a `.env` file:
    ```env
    GEMINI_API_KEY=your_api_key_here
    ```

## 🎿 Usage

1.  **Search**: Type your destination (e.g., "Stevens Pass", "Mt Baker", "Zermatt").
2.  **Select**: Choose the correct resort from the dropdown. AI-enhanced results are marked with ✨.
3.  **Analyze**: View the current metrics and the AI-generated gear protocol.
4.  **Plan**: Check the 5-day forecast to prepare for your multi-day mission.
